에이스 시리즈

집에서 아이와 함께 쓰는 학습 앱 모음입니다.수학에서 시작해 한자·영어·생각 에이스로 늘었고, 앱은 따로 쓰지만 별과 쿠폰은 에이스 홈 하나로 모입니다.

앱5개
공통별 지갑
정답 판정규칙과 데이터

왜 만들었나

문제은행식 학습지가 비용만큼 효과가 있는지 의문이었고, 이건 AI가 잘할 수 있는 일이라고 생각했습니다. '에이스'는 집에서 아이를 부르는 별명이에요.

다섯 앱

  • 에이스 홈별 지갑, 찬스 가게, 부모님 모드. 과목 앱으로 가는 입구입니다.자세히 보기 →
  • 수학 에이스초등 1~6학년 연산 39개 단원, 개념노트, 종이 학습지 사진 채점.자세히 보기 →
  • 한자 에이스한국어문회 8급~4급 1,000자, 복습 상자, 한자 도감.자세히 보기 →
  • 영어 에이스오늘의 한 마디, 주제 여행, 소리 탐정, 숫자 영어, 따라 말하기.자세히 보기 →
  • 생각 에이스생각나무에 물을 주며 푸는 6영역 19유형 사고력 문제.자세히 보기 →

별은 이렇게 돌아요

생각 에이스만 별 대신 나무에 물을 줍니다 (2026-10-25 정함).

  • 별 모으기수학·한자·영어에서 푼 만큼 별을 받습니다. 번 별은 각 앱의 기록에서 계산하고, 숫자를 따로 옮겨 적지 않습니다.
  • 별 쓰기찬스 가게에서 찬스(쿠폰)로 바꾸고, 힌트나 연습 메뉴의 무료 횟수가 지나면 별을 씁니다.
  • 부모님이 준 별남은 별에만 더합니다. 축하와 명예의 전당, 뱃지는 공부로 번 별만 셉니다.
  • 쿠폰 쓰기부모님이 에이스 홈에서 사용 처리합니다. 텔레그램 똑띠에서도 조회하고 쓸 수 있어요.

정해 둔 것들

  • 문제와 판정은 코드가문제는 규칙과 데이터로 만들고 정답도 코드가 판정합니다. AI는 키를 넣었을 때만, 수학의 힌트·사진 채점·결과 격려와 한자의 결과 격려에 씁니다. 영어와 생각 에이스는 AI를 쓰지 않습니다.
  • 공통 코드는 복사별 지갑 같은 공통 코드(src/ace)는 다섯 저장소에 같은 파일로 들어 있고, 고치면 다섯 곳에 똑같이 복사합니다. 한 곳에서 관리하는 방식이 더 낫지만, 지금은 이 방식으로 두었습니다.
  • 부모님 모드앱마다 4자리 PIN이 있고, 에이스 홈은 별과 쿠폰을 다루기 때문에 과목 앱과 다른 PIN을 따로 정합니다.

만든 방식

React · Vite · TypeScript · Tailwind로 만들고 GitHub Pages로 배포합니다. 기기 간 동기화는 Apps Script, AI는 Gemini를 선택적으로 씁니다. 수학 에이스에서 먼저 만든 구조를 한자·영어·생각 에이스가 이어받았습니다.
